# meta-torizon-sb-x86-testing

Custom layer on top of Common Torizon x86. Provides DISTRO
`torizon-sb-x86-testing`, currently identical to `common-torizon`.
MACHINE stays `intel-corei7-64`.

Select with `DISTRO=torizon-sb-x86-testing` in the environment before
`setup-environment`, or set it in `build/conf/local.conf`.
